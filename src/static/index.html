4. What the data tells us

  • Class balance: paper has 594 images but trash only 137. The model sees far fewer trash examples, so trash gets the lowest F1 score. Class weights were used to compensate.
  • Image variety: photos of one class differ in angle, light and object type (plastic bottles and plastic bags), so the model must learn shapes and textures. Augmentation and a pretrained MobileNetV2 help with this.
  • Brightness: cardboard is the darkest class (about 153) and glass the brightest (about 172). The gap is small, so brightness alone cannot separate the classes.
